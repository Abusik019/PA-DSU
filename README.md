## Введение
Личные кабинеты — платформа, предназначенная для облегчения учебного процесса и коммуникации между студентами и преподавателями.

## Кратко для собеседования
Самый интересный для меня проект — «Личные кабинеты» для колледжа, где мы с нуля сделали единую систему для студентов и преподавателей: лекции, экзамены, уведомления, личные и групповые чаты. Моя роль — Frontend Developer и Designer: я отвечал за UX/UI, архитектуру клиентской части на React + Redux Toolkit, роутинг, состояние приложения и интеграцию с backend API. Архитектуру продумывал на уровне модулей и пользовательских сценариев: разделил приложение на страницы, общие компоненты и Redux-срезы, чтобы проще масштабировать функционал и сопровождать код. Самым сложным было удержать консистентный пользовательский опыт при большом количестве ролей и экранов, при этом сохранив производительность и удобство разработки.
